# Many Turns — Parent Site

Operator house & software studio site for **Manyturns OÜ** (manyturns.co / manyturns.ee).

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS v4 · lucide-react · framer-motion

## Commands

```bash
npm run dev    # local
npm run build  # verify
npm run lint
```

- `NEXT.md` — open work
- `PRD.md` / `.cursorrules` — product & brand rules
