### Useful for Many Turns / consulting brand thinking

| Pattern | What they do | Why it might matter here |

| **Listen → craft → launch** (Process) | Dig deeper / ask what matters → strategy meets craft → living brand | Same operator arc as the journey spine: rooms first, then systems. Could inform how individual journeys later “merge into ventures” without becoming a worksheet. |
| **Channel Islands adjacency** | Jersey + Guernsey base; global clients; remote-comfortable | Same geography as Sam’s bank / gov / telecom turns. Proof that CI-rooted work can read serious and international — useful confidence for parent + consulting doors. |
| **Principles / values in plain English** | “No bollocks”, “Keep it human”, “Say what you mean”, “Right over easy” | Tone kinship with Many Turns / Kavsulting bans on corporate sludge. Steal *posture*, not the word list. |
| **People as proof** | Studio page = faces + principles; “Shed Sessions” journal | Human scale without a brand-grid carnival. Relevant if individual journeys become a visual later. |
| **Packaged journeys (Launch / Strategy / Scale / Fly)** | Named paths that cut decision paralysis | Metaphor cousin to “Continue this turn” — *named* next steps. Do **not** import their package ladder; the idea of named turns is already ours. |

### Ignore / do not import

- **Yellow hero + agency-portfolio chrome** — Wix Studio, work-reel hero, pill CTAs, stat strips (5000+ / 163 / …). Opposite of Many Turns navy/ivory parent and Kavsulting near-black hero.
- **Agency packaging & pricing frames** — brochure-site £5–25k band; Launch→Fly productisation. Many Turns is operator house + ventures, not a brand-agency shop window.
- **“Tribe / fans / unforgettable” activation language** — too campaign-agency for institutional parent / banking-adjacent trust.
- **Cloning “who you really are” as a headline** — their lock; our locks stay *Different paths. One journey.* and *Make the complex simple…*
- **Treating them as a competitor to beat visually** — different category (brand studio vs operator house). Context neighbour, not visual target.

### Sharp takeaway

Potting Shed is useful as a **Channel Islands peer that sequences brand work as truth → mark → world**, with blunt human principles. Many Turns should keep journey-first home and child-door fidelity; borrow only the *order of thinking* and CI seriousness — never their yellow/agency surface.
